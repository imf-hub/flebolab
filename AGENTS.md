# FLEBOLAB — convenciones del proyecto

- El repositorio y el alojamiento vigentes son GitHub y GitHub Pages. La carpeta canónica de la aplicación es esta raíz; no desarrollar ni publicar en el checkout histórico de Sites.
- La dirección visual aprobada es **clara/blanca por defecto, con acentos rojos IMF**. Conservar la distribución interactiva; no volver a un fondo negro por preferencias del dispositivo.
- Usar los originales de public/brand: horizontal en cabecera y sello en pie/favicon. No sustituirlos por iconos inventados, redibujos o imágenes generadas.
- Los cambios de tema deben conservar contraste de gráficos y escenas. No aplicar filtros, inversión o recoloreado a medios clínicos originales.
- Conservar la prioridad documental UIP/flebología, sociedades vasculares y fuentes complementarias; distinguir modelo educativo, datos de origen y calibración validada.
- Antes de publicar, ejecutar check:content, test y build con VITE_BASE_PATH=/flebolab/. Revisar los cambios visuales en navegador, incluyendo móvil cuando cambie la cabecera o el layout.
